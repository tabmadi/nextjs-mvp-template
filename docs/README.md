# Documentation

| Path | Genre | Holds |
| --- | --- | --- |
| [`adr/`](adr) | Decisions | Every load-bearing decision, each with a normative `Rules` section |
| `guide/` | Procedures | How to carry out a task |
| `reference/` | Lookups | Registries and tables looked up rather than read |

Genre decides the path ([ADR-0001](adr/0001-documentation-conventions.md)). A decision lives only in its ADR; a doc holds a procedure or live state.
